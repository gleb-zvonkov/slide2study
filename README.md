# slide2study 

Is an agenetic system that takes input pdf slides and outputs summaries and questions at three levels "remember", "understand", "apply". 
The system consists of three agents: a summary generator agent, a question generator agents, and a grader agent.

## Motivation
Students in content-heavy courses often rely on lecture slides as their main study resource, but slides provide limited support for active learning. They summarize key concepts without offering practice, feedback, or guidance. Slide2Study addresses this gap by converting raw slides into summaries, questions, and instant grading, turning passive slide review into a structured, interactive learning process.

## How the System Works
1. The user uploads a PDF.    
2. The frontend extracts per-page text using pdf.js.   
3. Then for each slide:   
      a. Summary Agent: generates a summary.   
      b. Question Agent: produces questions at three levels.   
      c. Grader Agent: grades the users answers as correct or incorrect.      
     &nbsp;&nbsp;&nbsp;   If correct: move to next level question.         
      &nbsp;&nbsp;&nbsp;  If incorrect: enter free-talk mode, when ready move to next question.


## Dataset Construction (self_labled_datasets)
To evaluate each agent in slide2study, we created four datasets using course materials from U of T’s ANA200H1: Human Visceral Anatomy instructed by proffesor Barbra Ballyk. 

1. Bloom-Level Question Dataset — `questions_labeled.csv`         
A set of 115 anatomy questions labeled as Remember, Understand, or Apply.
Remember questions came from past exams.
Understand questions were created by rewriting Remember questions to involve explanation or comparison.
Apply questions were created by adding short clinical scenarios requiring transfer of knowledge.

2. Question Relevance Dataset — `text_question_relevance.csv`           
Pairs each slide’s text with a question labeled as relevant or irrelevant.
Relevant pairs came from weekly quiz questions tied directly to the slide.
Irrelevant pairs were created by matching weekly quiz questions to unrelated slides.

3. Grader Dataset — `question_answers_graded.csv`                   
A set of multiple-choice anatomy questions paired with answers labeled correct or incorrect.
Correct examples use the actual exam key.
Incorrect examples pair the same question with a distractor option.

4. Summary Fidelity Dataset — `text_summary_fidelity.csv`               
Slide text paired with spoken lecture transcript segments.
Fidelity examples pair each slide with transcript segment where the professor explains that slide.
Infidelity examples pair the slide with a mismatched transcript segment.


## Evaluation 
We use each dataset to evalute how well our system works.         

1. Question Agent Bloom level Evaluation                 
Using the `text_question_relevance.csv` we prompt engineering a bloom level evalutor.
We generate questions using our question generator. 
We evaluted the questions ussing the bloom level evalutor.   
These results are in `prompt_engineering_approach/bloom_level_evaluation.py`.
Using the `text_question_relevance.csv` we fintinue a bloom level evalutor.
We generated question using our question generator.
We evaluted the questions using the bloom level evaluator.
These results are in `prompt_engineering_approach/bloom_level_evaluation.py`.

2. Question Agent Relevance Evaluation        
Using the `text_question_relevance.csv` dataset we built a relevance evaluator.
We generated questions using our question generator.
We evaluated each generated question against the slide text using the relevance evaluator.
These results are in `prompt_engineering_approach/question_relevance_evaluation.py` and `fine_tuning_approach/question_relevance_evaluation.py`.  

3. Summary Fiedlity Evaluation         
Using the `text_summary_fidelity.csv` dataset we built a fidelity evaluator.
We generated summaries using our summary generator.  
We used the fidelity evaluator to classify each summary as fidelity or infideltiy.
These results are in `prompt_engineering_approach/fidelity_evaluation.py` and `fine_tuning_approach/fidelity_evaluation.py`.   

4. Grader agent Evaluation        
Using the `question_answers_graded.csv` dataset we evaluated how accurately the grader agent identifies correct vs. incorrect answers.
These results are in `prompt_engineering_approach/grader_evaluation.py` and `fine_tuning_approach/grader_evaluation.py`.
